# Einführung in Markdown

Markdown ist eine vereinfachte Auszeichnungssprache, die sich leicht
lesen und schreiben lässt. Dieser Text verwendet ausschließlich
Konstrukte, die in *CommonMark* und *GFM* gleichermaßen verstanden werden.

## Textauszeichnung

Überschriften, **fette** und *kursive* Schrift sowie `Inline-Code` sind
die Grundbausteine. Ein Absatz wird durch eine Leerzeile beendet.

## Listen und Zitate

- Einfache Listen verwenden Bindestriche
- Sie lassen sich auch verschachteln:
  - Zweite Ebene
  - Noch ein Punkt

> Zitate beginnen mit einem Größerzeichen
> und können mehrere Zeilen umfassen.
